# ShopKart

ShopKart is an e-commerce website developed using the MERN stack. Users can browse products, add items to their cart, place orders, and manage their accounts. It also includes an admin panel to manage products, users, and orders.

## Technologies Used

- **Frontend:** React.js, Redux, HTML, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Other:** Stripe, Cloudinary, JWT

## Features

- User registration and login
- View and search products
- Filter products by category and price
- Add products to cart
- Place orders and make payments
- View order history
- Product ratings and reviews
- Admin panel for managing products, users, and orders

## How to Run

1. Download or clone the project.
2. Install the required packages:

   `npm install`

   `npm install --prefix frontend`

3. Add the required database and API credentials in `backend/config/config.env`.
4. Start the backend:

   `npm run dev`

5. Start the frontend:

   `npm start --prefix frontend`

6. Open `http://localhost:3000` in your browser.
